# The stream screen

## Corner shortcuts

The corners of the stream have hidden buttons, so nothing covers the game until you need it. Each time a stream starts, hints point at them and then fade out.

| Corner       | What it does                                                         |
| ------------ | -------------------------------------------------------------------- |
| Top right    | Tap, then the gear, for the stream menu                              |
| Top left     | Tap, then the Xbox logo (Steam's Guide button) or the keyboard       |
| Bottom right | Turn [frame generation](picture.md#frame-generation) on and off      |
| Bottom left  | Mute or unmute the mic, when [voice chat](audio.md#voice-chat) is on |

With a controller, hold **View + Menu** for a second to open the stream menu.

## The stream menu

The game keeps running behind the menu. From it you can:

- **Resume**, **Type with the keyboard** and **Mute microphone**.
- **Quit game** and **Quit** (see [Quitting](#quitting)).
- See the phone's battery and temperature.
- See the resolution, frame rate, bitrate, codec and HDR the stream asked for, and the size the PC is actually streaming at.
- [Check connection](connection.md#check-connection).
- Change display, controller, virtual controls and audio settings mid-game.
- [Share diagnostics](troubleshooting.md#reporting-a-problem) or report a problem, without leaving the game.

## Typing with the keyboard

Tap the screen with three fingers, tap the top-left corner and then the keyboard button, or choose **Type with the keyboard** in the stream menu. Do the same again to close it.

What you type goes to whatever has focus on the PC, such as a search box in Big Picture, password fields included. A bar above the keyboard adds Esc, Tab and the arrow keys. If a game or Steam asks for text, the keyboard opens by itself.

## Quitting

- **Quit game** closes the game on your PC and keeps streaming, so you land back in Big Picture to pick something else.
- **Quit** ends the stream and closes the game too. It needs a second press to confirm.

Both close the game the way you would at the PC (Alt+F4 on Windows and Linux, Cmd+Q on a Mac), so a game may ask before closing, and anything unsaved is lost. They only act when Steam reports a game is running, never on the desktop or in Big Picture.

## Battery and heat

The stream menu shows the battery and the phone's temperature, and the app warns you when the phone gets hot. Dropping to 30 fps in Settings helps it cool down.
