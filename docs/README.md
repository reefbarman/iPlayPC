# iPlayPC feature guides

Everything iPlayPC does, grouped by topic. The [main README](https://github.com/reefbarman/iPlayPC#readme) has the highlights and install steps. The [changelog](https://github.com/reefbarman/iPlayPC/blob/main/CHANGELOG.md) lists what changed in each release. These guides are also published at [reefbarman.github.io/iPlayPC](https://reefbarman.github.io/iPlayPC/).

| Guide                                                       | What's in it                                                                                          |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| [PCs and setup](pcs-and-setup.md)                           | Setting up the PC, finding and pairing it, PC settings, waking a sleeping PC, Mac hosts               |
| [Picture](picture.md)                                       | Resolution, frame rate, bitrate, codecs, HDR, Fit/Zoom, upscaling and MetalFX, 120 Hz, frame generation, stats |
| [Controllers](controllers.md)                               | How your controller appears on the PC, rumble, gyro aiming, Controller Test                           |
| [Touch and virtual controls](touch-and-virtual-controls.md) | On-screen controls and their options, touch as a mouse                                                |
| [Connection](connection.md)                                 | Auto bitrate, Check connection, reconnecting after a dropout                                          |
| [Audio](audio.md)                                           | Game audio and voice chat                                                                             |
| [The stream screen](stream-screen.md)                       | Corner shortcuts, the stream menu, typing with the keyboard, battery and heat, quitting               |
| [iPhone Duo](iphone-duo.md)                                 | Inner and outer screens, folding                                                                      |
| [Help and troubleshooting](troubleshooting.md)              | Reporting a problem, common fixes, known limitations                                                  |
| [Licences and source code](licensing.md)                    | What the AGPL means for you, Settings › About, getting the source for a version, bundled components   |
| [Privacy policy](privacy.md)                                | What iPlayPC keeps on your device, who it talks to and its permissions                                |

Settings paths in these guides look like **Settings › Display**. Open Settings from the gear on the PC list, or during a stream from the top-right corner or by holding **View + Menu**. Everything except the video settings is also in the stream menu, so you can change it while you play.
